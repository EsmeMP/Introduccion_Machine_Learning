# Introduccion_Machine_Learning

# Introducción al Machine Learning

Este proyecto presenta los conceptos fundamentales del aprendizaje automático, utilizando **Python** y librerías como `pandas`, `scikit-learn` y `seaborn`.  
Se abordan temas como **preprocesamiento de datos**, **ingeniería de características**, **escalado** y **evaluación de modelos**.

---

## Librerías principales

### Seaborn (`sns`)
Librería para crear gráficos estadísticos avanzados con menos código.  
Permite visualizar patrones, correlaciones y distribuciones de los datos de manera eficiente.

# Conceptos Importantes

## Escalado
- **Min-Max Scaling:** normaliza los valores en un rango entre 0 y 1.  
- **Standard Scaling:** ajusta los datos a una media 0 y desviación estándar 1.

## Ingeniería de características
Permite detectar patrones más profundos dentro de los datos, creando o transformando variables que ayudan a mejorar la predicción del modelo.

## Métricas del modelo de Machine Learning
- **Error Cuadrático Medio (EMC):** detecta predicciones alejadas del valor real.  
- **RMC (Raíz del Error Cuadrático Medio):** facilita la interpretación en las mismas unidades de la variable objetivo.  
- **MAE (Error Absoluto Medio):** no da pesos extra a los valores atípicos, mostrando un panorama claro del error típico.  
- **R² (Coeficiente de Determinación):** un valor bajo indica que el modelo no logra explicar bien la variabilidad de los datos.
